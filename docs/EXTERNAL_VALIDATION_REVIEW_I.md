# I: genuinely unseen-source feasibility review

Next standing research item after accepted H. This is a feasibility and
provenance audit, not another parameter grid or an authorization to change the
main population. No new performance claim is registered by this document.

1. Read actual original/verified availability ledgers and cache manifests. List
   sources outside the frozen53-source population and why they were excluded.
   Distinguish missing media, alignment failures, quarantined frame-count cases,
   extra cached sources, original split and prior annotation/label-summary use.
   Do not inspect new candidate outcomes to choose an easy test set.
2. A candidate is not genuinely unseen merely because it was excluded from
   verified-population-v2. It must be outside all main training/validation/test,
   tuning, diagnostics and subsequently inspected source experiments. The
   original broad annotation inventory may already have summarized excluded
   source labels. Record prior-inspection unknowns explicitly; do not assume
   independence from missing documentation.
3. Existing alignment failures remain disqualifying until the P03 mapping,
   decode/timebase and visual gates are independently satisfied in a separately
   versioned population. Never silently repair the old denominator or reuse a
   quarantined cache as accepted evidence. Public geometry review can proceed
   without examining new reference labels.
4. If no local source qualifies, write that result honestly. Research a concrete
   external-validation candidate using official dataset/paper/license sources:
   target definition, person-pair/time mapping, accessible authorized media and
   annotations, track availability, frozen-backbone training exposure, cost,
   download/version hashes and expected alignment/inference work. Do not call
   exposure to pretraining data an independent clinical or new-person test.
5. Before any new evaluation outcomes, register an exact source population,
   eligibility/unknown rules, frozen q and development recipe, audit budgets,
   seeds, endpoints and allowed comparisons. Never retune on external labels.
   Distinguish dataset-transfer validation from per-frame recognition accuracy.
   The current course report and all negative results remain intact.
6. Prefer released compatible caches/CPU work. Before optional new inference,
   assess resource cost and actual GPU/Kaggle activity; do not interfere with
   the user's other agent. Use project-isolated credentials only when needed,
   never print them. Honor official access/license restrictions; if an actual
   human prerequisite is required, explain the precise missing requirement.

Save a cited feasibility report and durable status under new I files. A lack of
qualifying local sources is useful evidence, not a reason to relabel old ones
as fresh. If external evaluation is infeasible, register a bounded, useful next
scientific question or reproducibility improvement rather than looping on the
same inspected test set. The standing10-minute continuation remains active
until the user stops it; no automatic positive/novelty claim is expected.
