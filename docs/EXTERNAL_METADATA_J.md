# J: external-data metadata and alignment gate

Registered 8 November 2026 before any external performance evaluation. This is
an acquisition/schema gate, not a new result or a change to the main study.

## Ordered bounded work

1. Check the author-linked AVA-LAEO annotation archive and current UCO-LAEO
   release using unauthenticated HEAD requests, timeout 12 seconds each. Save
   status, MIME type, size and final hostname, never authentication redirects or
   session tokens. Do not bypass sign-in or export browser cookies.
2. If an official annotation archive is accessible, allow at most 64 MiB for
   AVA annotations, in a new ignored directory. Record SHA256 and byte count.
   List archive members; read only README/license/schema documents and author
   loader code. Do not extract arbitrary paths, execute downloaded code, load
   pickles, inspect class proportions or calculate performance. An oversized
   archive is a documented gate, not permission for an unbounded download.
3. Establish AVA movie/timestamp/person-pair keys, ambiguous-label rules, body
   versus head geometry, temporal sampling, official validation membership and
   the need for raw scene frames. Check source-content overlap with VSGaze
   components. Unknown pretraining exposure must remain unknown.
4. For UCO, prefer the author-provided extracted frames matching the annotations;
   never assume the released videos have identical alignment. Inspect the
   official split configuration and public geometry contract. Download no media
   until storage, rights/access and alignment work are understood. A VSGaze
   component evaluates downstream transfer, not a wholly unseen backbone domain.

No GPU, Kaggle request, reference-label analysis or model fit is authorized by
this gate. Keep existing caches/populations/results immutable. A public metadata
failure is preserved and can be retried after the underlying access condition
changes. Do not substitute a third-party reupload or generic AVA action labels.

## Evaluation contract required after the gate

A separate versioned protocol must fix the actual source ledger/hash and label
mapping, eligibility and unknown policy, scene/head/time mapping, checkpoint and
preprocessing hashes, and inference completeness before any outcome readout.
Use the frozen ChildPlay-trained development recipe; no external-label tuning.
The proposed estimand is prevalence among the release's eligible annotated
unordered pairs at its annotated times. AVA's action-selected frames cannot
estimate prevalence in all movie frames or natural interactions.

Proposed comparison, contingent on compatible head/scene inputs: uniform
difference estimation, frozen K4 score allocation with weight 1, and the same
allocation/queries with weight 0.5. Set four exact unique-label budgets to
floor(0.05/0.10/0.20/0.40 times N), minimum feasible stratum allocation as in the
frozen implementation, 1,000 draws per method/budget, seeds 200000 + draw index
and a newly registered stream ID. Primary endpoint: RMSE ratio weight0.5/1 at
10%; secondary bias, exact design variance, interval coverage/width and every
loss/tie. Do not choose stream, exclusions, hyperparameters or endpoints using
external outcomes. Register the final numerical budgets and stream before run.

The current document intentionally does not claim an executable performance
protocol: the exact population and geometry are not established. Next output is
a reproducible metadata/alignment decision, including a negative one.
