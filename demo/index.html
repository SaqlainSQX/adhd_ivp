03 / 03 · METHOD & LIMITS

An estimate you
can trace back.

The course contribution is a controlled, reproducible annotation study: verified data, exact budgets, comparable estimators and explicit negative results.

01

Freeze the population

53 verified public sources; 191,956 training, 25,139 validation and 10,316 test pair-frames. Unknown references and unresolved media-alignment failures are excluded explicitly.

02

Share the predictions

All methods reuse the same frozen temporal MTGS-DINO scores. “Static” describes the error-guidance features, not a different backbone. Score/entropy controls use no learned error predictor.

03

Fix queries before labels

Training defines error strata and allocation moments; validation selects allocation settings. Each test audit saves its exact query plan before selected references are retrieved.

04

Correct the residual

Combine the full model mean with weighted sampled errors. Strata are sampled without replacement, with positive inclusion and a fixed total number of labels.

COMMON DIFFERENCE ESTIMATOR

estimate = mean(q) + Σₕ (Nₕ / M) × meanₛₐₘₚₗₑ,ₕ(y − q)

M is the population size, Nₕ is the size of stratum h, q is a frozen prediction, and y is a queried reference. Human-only estimation sets q to zero. The contextual-surrogate control uses its frozen adjusted q.

What the evidence supports

Guided allocation improves fixed-corpus label-count efficiency over uniform controls. Extra temporal guidance did not beat the locked static method. The registered simple controls test whether learned guidance is necessary.

The full original comparison, all losses and all exploratory follow-ups remain available in the repository report.

Where the conclusions stop

  • Available-media subset and provided benchmark head tracks.
  • Only three validation sources; inspected test data make this exploratory.
  • Reused development labels are an additional cost.
  • Approximate intervals can under-cover; calibration may not transfer.
  • No clinical validation, diagnosis or measured human-time saving.
